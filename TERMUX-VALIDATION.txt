WaffleHouse-Client-Termux Build 0.8 — RTP/audio source audit
============================================================

Scope
-----
This audit was performed after Build 0.7 successfully registered to the PBX
(200 OK) but pjsua_call_make_call() failed while Termux PortAudio/OpenSL ES
attempted to initialize microphone capture.

RTP/RTCP source review
----------------------
PASS: PJMEDIA owns a dedicated media ioqueue and one RTP worker thread.
PASS: SIP/RTP creation is decoupled from Android hardware audio by starting
      Termux on PJSIP's null sound device.
PASS: Call diagnostics retain local/remote RTP and RTCP addresses.
PASS: Call diagnostics retain codec/clock rate, TX/RX packets and bytes,
      loss/discard, jitter, RTT and jitter-buffer delay.
PASS: Existing optional STUN, ICE and SRTP account plumbing is retained.
PASS: RFC2833 DTMF path is retained.

Audio I/O hardening
-------------------
PASS: Hardware audio is deferred until negotiated call media is active.
PASS: A microphone/full-duplex failure no longer aborts INVITE creation.
PASS: Failed capture falls back to playback-only mode when Android output can open.
PASS: If playback also fails, RTP stays alive on the null device rather than
      terminating the call.
PASS: /audio-reopen uses a playback-only fallback on Termux.
PASS: Capture and playback bridge attachment errors are isolated.
PASS: Installed helper `wafflehouse-audio-preflight` performs a one-second
      Termux:API microphone permission/capture test.

Important Android limitation
----------------------------
The normal Termux application does not itself declare RECORD_AUDIO. Native
OpenSL ES microphone access therefore depends on the matching Termux:API Android
add-on/shared Termux UID having microphone permission. `pkg install termux-api`
installs the command-line client only, not the Android add-on APK.

Validation
----------
Termux parity/static source gate: 53/53 PASS.
All project shell scripts: bash -n PASS.
Native Android call/RTP/audio runtime still requires testing on the target phone.
