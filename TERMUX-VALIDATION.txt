WaffleHouse-Client-Termux Build 0.9 — responsive TUI + retained SIP/RTP validation
==============================================================================

Build baseline
--------------
Build 0.9 is based directly on the Build 0.8 source that completed a successful
real-device SIP registration and test call with working two-way audio on the target
Android/Termux phone. No SIP/RTP/audio behavior was intentionally removed or changed
by the responsive-TUI work.

Responsive terminal review
--------------------------
PASS: live PTY size is sampled with TIOCGWINSZ on Termux.
PASS: ncurses resizeterm() is called when Android changes rows/columns.
PASS: layout reflows for portrait, landscape, split-screen and soft-keyboard resize.
PASS: status and input rows remain anchored at the bottom.
PASS: optional connection/footer chrome collapses before conversation space.
PASS: narrow terminals use compact header/status/input variants.
PASS: minimum interactive geometry is 24x6 with a safe resize notice below that.
PASS: side panes are automatically suppressed on narrow screens.
PASS: popup/dialog widths and heights are bounded by the live terminal size.
PASS: BBS ANSI model resizes to the visible content pane.
PASS: Telnet NAWS is updated live after resize when NAWS was negotiated.
