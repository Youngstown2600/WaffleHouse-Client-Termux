WaffleHouse-Client 3.2-Termux — source audit
2026-08-22

Baseline
--------
Ported from the user-supplied WaffleHouse-Client 3.1r8 source archive.

Termux changes
--------------
- New QCoreApplication entry point: src/main_termux.cpp.
- Dedicated CLI-only CMake target; Qt Gui and desktop Qt Widgets are not linked.
- Product/version identity changed to WaffleHouse-Client 3.2-Termux.
- Former media-edition sub-brand removed from retained source/documentation branding surfaces.
- Responsive ncurses startup presentation for narrow phone terminals.
- Minimum UI size reduced to 30x8 with safe dialog-width/height fitting.
- Added /menu compact command map.
- Added Android/Termux runtime detection.
- Added Termux shared Downloads preference for accepted file transfers.
- Added termux-media-player notification playback and termux-open-url browser handoff.
- Added Termux builder, dependency installation, install/uninstall/update lifecycle.
- Removed Perl/CPAN from the builder path by installing a minimal local xdg-utils compatibility provider before qt6-qtbase.
- Added managed PJSIP 2.17 Termux configuration with external PortAudio/OpenSL ES.
- Preserved PJSIP multi-account/call sizing and existing SIP lifetime compatibility guard.

Feature-preservation surfaces retained
--------------------------------------
- AIM/OSCAR
- IRC and IRC slash commands
- Telnet/BBS and ANSI terminal model
- saved profiles and multiple simultaneous connections
- Secure DM / Secure Rooms / fingerprints / trust controls
- secure and unsecured file transfer plus direct-transfer path
- multi-account SIP softphone, calls, DTMF, hold/resume/mute, SIP log and ladder
- audio-device list/use/auto controls
- themes and notifications
- local media, HTTP/HLS, SHOUTcast/Icecast, queue/playlists, seek, volume, mute, shuffle/repeat, EQ

Baseline media behavior
-----------------------
The supplied 3.1r8 baseline had already removed dedicated YouTube extraction/playback. 3.2-Termux keeps that behavior and retains `--ytdl=no` for mpv.
