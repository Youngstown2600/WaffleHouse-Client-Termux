Environment limitation
----------------------
The release-preparation container does not contain Termux's Qt 6, ncursesw,
libsodium, or PJSIP 2.17 development packages and is not Android. Therefore a
real binary compile and live Android network/audio smoke test were not possible
here. The final compile/runtime validation should be run on the target device
with ./build.sh; the builder installs/validates the Termux dependencies and
runs these regression gates before compilation.
