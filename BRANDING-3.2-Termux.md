# WaffleHouse-Client 3.2-Termux Branding

The product name for this package is **WaffleHouse-Client 3.2-Termux**.

The previous media-edition sub-brand has been removed from application strings, help text, desktop metadata, documentation, tests, and release filenames. Media and internet-radio playback remain normal WaffleHouse-Client features.

The Termux CLI uses `WAFFLEHOUSE-CLIENT` in its compact startup banner and `WAFFLEHOUSE-CLIENT 3.2-TERMUX [CLI]` in the main terminal header.
